பாட்டி வீடு (Patti Veedu · Grandma's House) 10.4 — Windows
=========================================================

தொடங்குவது எப்படி
1. இந்த zip-ஐ முழுதாக extract செய்யுங்கள் (zip-க்குள்ளேயே திறக்க வேண்டாம்).
2. PattiVeedu.exe மேல் இரண்டு முறை கிளிக் செய்யுங்கள்.
3. "Windows protected your PC" வந்தால் → "More info" → "Run anyway".

PattiVeedu.exe-உம் resources.neu-உம் ஒரே folder-இல் இருக்க வேண்டும்.

விண்டோ திறக்கவில்லை / வெறுமையாக இருந்தால்:
  Microsoft Edge WebView2 Runtime நிறுவுங்கள் (Windows 11-இல் ஏற்கெனவே இருக்கும்):
  https://developer.microsoft.com/microsoft-edge/webview2/

கட்டுப்பாடுகள்
  W A S D      நட
  மவுஸ்        சுற்றிப் பார் (திரையைக் கிளிக் செய்தால் மவுஸ் பூட்டப்படும்)
  Shift        ஓடு (சத்தம் கேட்கும்!)
  C / Ctrl     குனி — சத்தமில்லாமல் நட
  E            எடு / திற / படி / ஒளிந்துகொள் / வெளியே வா
  G            கீழே போடு
  F            டார்ச் ஆன் / ஆஃப்
  J / Tab      டைரி (குறிப்புகள், வரைபடம்)

  Esc / P      இடைநிறுத்தம் (புதிர்ப் பலகையை மூடவும் Esc)

விளையாட்டு தானாக சேமிக்கும் — மீண்டும் திறந்தால் "தொடர்ந்து விளையாடு".
அமைப்புகள் → தானாக கேமரா திரும்புதல் (ஆன்/ஆஃப்): நடக்கும் போது பார்வை நீங்கள் போகும் பாதையை மெதுவாகப் பின்தொடரும்.

ஹெட்போன் போட்டு விளையாடுங்கள் — கொலுசு சத்தம் எந்தப் பக்கம் என்று கேட்டால்
பாட்டி எங்கே என்று தெரியும்.

---------------------------------------------------------

How to start
1. Extract the whole zip (don't run it from inside the zip).
2. Double-click PattiVeedu.exe.
3. If "Windows protected your PC" appears → "More info" → "Run anyway".

Keep PattiVeedu.exe and resources.neu in the same folder.
Blank or no window? Install the Microsoft Edge WebView2 Runtime (already on Windows 11).

Controls: WASD move · Mouse look (click to capture) · Shift run · C/Ctrl crouch ·
E use / hide / come out · G drop · F torch · J/Tab diary · M map · Esc/P pause.
Graphics always run on High. The game saves itself — reopen it and press Continue.
Settings and best time are saved between launches.
Settings → Auto camera (On/Off): while you walk, the view gently turns to follow your path.
